# About AWS Student Builder Groups

## What the program is

AWS Student Builder Groups is a global network of university clubs focused
on hands-on cloud and AI learning. Chapters run workshops, build projects,
and host an annual campus hackathon.

not covered in the club documents.

## Chapter leads and rotation

Track leads (frontend, backend, cloud infra, AI/ML) rotate each semester.
Announcements about new leads go out in the club channel at the start of
each term.

## Getting more involved

Members who want to help run workshops or mentor newer members should reach
out to the group leader directly. There's no formal application — consistent
participation is the main signal chapter leads look for.
