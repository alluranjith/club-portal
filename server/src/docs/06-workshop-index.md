# Past and Upcoming Workshops

## Schedule pattern

Workshops run twice a month, on the first and third Thursday, 6:00–7:30 PM,
in the CS department seminar hall. Recordings are posted within a week.

## Recent workshops

- "Intro to EC2 and S3" — hands-on account setup and first static site
- "Serverless APIs with Lambda" — building a REST API without a server
- "RAG with Bedrock Knowledge Bases" — document search + Claude answers
- "Auth patterns: Cognito vs rolling your own" — trade-offs for student
  projects
- "Git for team hackathons" — branching, PRs, and avoiding merge conflicts
  under time pressure

## How to request a topic

Post in the club channel with the topic and why it would help your project.
Chapter leads review requests monthly when planning the next two sessions.

## Attendance

Workshops are open to all members. No RSVP required, but arriving by 6:00
guarantees a laptop-adjacent seat near a power outlet.
